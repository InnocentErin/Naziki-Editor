# 时间轴模块化拆分规划文档

> 生成日期：2026-07-26  
> 目标：将时间轴系统按照"宏观时间轴（maintimeline）"、"微观时光屋（microtimeline）"、"时间轴方块（timelineclip）"三大核心模块进行系统性拆分，确保各模块高内聚、低耦合、职责清晰。

## 四、模块详细功能划分

### 📦 Module 1: Shared（共用基础模块）

**定位**: 所有时间轴模块的共同基础，提供纯数学/算法级别的工具类，不应包含UI逻辑。

| 子模块 | 文件 | 核心功能 | 输入 | 输出 |
|--------|------|---------|------|------|
| 时间引擎 | `ChartTimeEngine.cs` | Tick→秒换算、音符锚点时间表达式解析 | tick值/时间表达式字符串 | 绝对秒数 |
| 坐标引擎 | `TimelineCoordEngine.cs` | 时间↔像素坐标换算、缩放级别管理 | 秒数/像素 | 像素/秒数 |
| 锚点引擎 | `TimelineAnchorEngine.cs` | 寻找最近音符并生成锚定表达式 | 当前秒数+音符列表 | 锚定字符串 |
| 排版引擎 | `TimelineLayoutEngine.cs` | 基于Layer/Order的智能排版 | ProjectDataContext | 修改后的实体Order |
| 关键帧解码器 | `KeyframeDecoder.cs` [新] | 将关键帧列表压平为视觉时间节点 | 实体+属性名+起始时间 | List<DecodedKeyframeBox> |
| 关键帧反写器 | `KeyframeWriteBack.cs` [新] | 拖拽后将视觉位移反写回底层数据 | 实体+目标状态+新时间 | void（修改实体） |
| 关键帧缩放器 | `KeyframeScaler.cs` [新] | 等比例缩放方块内所有关键帧 | 实体+旧/新时间范围 | void（修改实体） |
| 时间表达式更新器 | `TimeExpressionUpdater.cs` [新] | 对时间表达式应用增量 | 原始时间表达式+增量 | 新时间表达式 |
| 结束时间计算器 | `EntityEndTimeCalculator.cs` [新] | 计算实体结束时间（含Destroy检测） | 实体+起始时间 | 结束秒数/InfiniteEndTimeSentinel |
| 解码数据模型 | `DecodedKeyframeBox.cs` | 解码关键帧的数据容器 | - | - |

**依赖关系**: Shared 模块不依赖任何其他时间轴模块，仅依赖 `Models/` 和 `State/`。

### 📦 Module 2: MainTimeline（宏观时间轴模块）

**定位**: 负责宏观时间轴的全部功能——轨道渲染、方块管理、音频同步、播放控制、缩放、全局排版。

#### 2.1 Core 层

| 子模块 | 文件 | 核心功能 |
|--------|------|---------|
| 服务接口 | `IMacroTimelineService.cs` | 定义宏观时间轴操作契约 |
| 服务实现 | `MacroTimelineService.cs` | 时间/坐标换算、SnapTime、结束时间计算、时间表达式更新、关键帧缩放 |
| 数据模型 | `MacroTimelineModels.cs` [新] | MacroTimelineConfig、ZoomState等 |

#### 2.2 UI 层

| 子模块 | 文件 | 核心功能 |
|--------|------|---------|
| 数据引擎 | `TimelineDataEngine.cs` | 从ProjectDataContext构建TrackGroup/Track/Clip数据树 |
| ViewModel | `TimelineViewModel.cs` | 时间轴主ViewModel，管理TrackGroups、缩放、播放状态 |
| 轨道模型 | `MacroTimelineModels.cs` (UI/ViewModels) | TimelineTrackGroupModel、TimelineTrackModel、MacroClipModel |

#### 2.3 Views 层

| 子模块 | 文件 | 核心功能 |
|--------|------|---------|
| 主控件 | `TimelineControl.xaml/.cs` | 宏观时间轴容器，协调所有子控件 |
| 刻度尺 | `TimelineRuler.cs` [新] | 顶部时间刻度尺渲染与更新 |
| 播放游标 | `TimelinePlayhead.cs` [新] | 红色播放游标拖拽、位置更新、智能跟随 |
| 音频栏 | `TimelineAudioBar.cs` [新] | 音频波形绘制、迷你缩略图、视口滑块 |
| 音符尺 | `TimelineNoteRuler.cs` [新] | 底部音符刻度尺渲染、缩放更新 |
| 轨道渲染器 | `TimelineTrackRenderer.cs` [新] | 轨道组/轨道/方块的创建、布局、刷新 |

**TimelineControl 精简后职责**（从9大职责缩减为协调器）：
1. ✅ 协调各子控件的生命周期
2. ✅ 处理滚动同步
3. ✅ 提供缩放入口（Ctrl+滚轮）
4. ✅ 管理微观编辑器Tab切换
5. ✅ 实现IShortcutAware接口
6. ❌ ~~轨道渲染~~ → `TimelineTrackRenderer`
