# 📋 Naziki Editor 产品设计分析报告

---

## 一、项目架构概览

当前项目采用 **WPF + .NET 10** 构建，核心架构分为三层：
- **Core 层**：包含解析器、仓储、编解码、时间引擎、音频引擎等业务逻辑
- **Models 层**：包含 `StoryboardModels.cs`（7大实体类型 + 完整状态属性）、`NazikiProjectModel`、`ChartModels` 等
- **Views 层**：7大核心模块控件 + 属性编辑器 + 通知系统

**当前工作流**：`启动 → 导入谱面(.json) → 导入故事板(.json) → 编辑 → 保存`，**无法从零创建新故事板**。

## 三、用户交互流程分析

### 当前完整交互流程

```
启动应用 → [导入谱面] → [导入故事板] → Tabs分类浏览 → 选中事件 → 查看属性面板(只读)
                                                                   → 双击/按钮 → 打开属性编辑器弹窗 → 修改 → 保存关闭
                                                                   → JSON源码Tab → 编辑 → 应用
              → 音符管理 → 过滤音符 → 选中 → 一键导入事件 → 自动创建NoteController
              → 素材列表 → 双击 → 打开属性编辑器 → 创建事件
              → 时间轴 → 播放/暂停 → 查看轨道
```

### 关键断点与问题

#### 🔴 断点 1：无法从零开始创建新故事板
- **问题**：整个应用以"导入已有故事板"为唯一入口，菜单栏的"新建项目"仅显示提示"功能将在后续版本中实现"
- **影响**：用户无法在不依赖外部文件的情况下开始创作

#### 🔴 断点 2：强制导入顺序锁
- **问题**：必须"先导入谱面 → 再导入故事板"。`EventListControl` 中有 `ChartMissingOverlay` 结界，`ImportStoryboard` 也做了硬拦截
- **影响**：即使用户只想设计纯视觉故事板（不涉及音符），也无法绕过

#### 🔴 断点 3：预览画布形同虚设
- **问题**：`CanvasControl` 的"画面实时预览"标签页仅显示 `TextBlock "预览画布 800x600"`，完全没有渲染任何故事板对象
- **影响**：用户无法获得任何视觉反馈，编辑变成"盲操"

#### 🔴 断点 4：属性面板只读 → 必须弹窗编辑
- **问题**：属性面板仅展示属性，所有编辑必须通过 `PropertyEditorWindow` 弹窗完成
- **影响**：每次微调属性都需要"打开弹窗 → 编辑 → 确认关闭"，操作路径过长

#### 🔴 断点 5：时间轴无关键帧可视化
- **问题**：时间轴展示了轨道结构，但没有渲染关键帧方块，用户无法直观看到动画的时间分布
- **影响**：时间轴沦为"播放/暂停"工具，失去了核心的编辑功能

#### 🟡 断点 6：缺少"添加 Sprite"和"添加 Note Controller"入口
- **问题**：事件列表的4个快速添加按钮涵盖了 Text/Line/Scene/Template，但遗漏了最常用的 Sprite 和 Note Controller
- **影响**：用户只能通过素材列表→双击或音符列表→导入来间接创建

#### 🟡 断点 7：缺少拖拽创建的工作流
- **问题**：素材列表中的素材无法拖拽到画布或时间轴来创建对象
- **影响**：不符合主流设计工具（Figma/After Effects）的直觉操作

#### 🟡 断点 8：Note Selector 无 GUI 构建器
- **问题**：规格中 note 选择器（type/start/end/direction/min_x/max_x）是核心功能，但只能通过 JSON 手写
- **影响**：用户无法可视化的选择"ID 250-275 的所有 Click"或"屏幕左半边的所有音符"

#### 1.1 改造 `NewProject` 命令

在 [`MainWindow.xaml.cs`](file:///d:/Naziki_Editor/Naziki Editor/Naziki Editor/Views/MainWindow.xaml.cs#L468-L472) 中，当前 `NewProject` 仅显示提示信息。应改为：

```csharp
_commandDispatcher.Register("NewProject", () =>
{
    if (!ResolveDataConflictIfNeeded()) return;
    
    // 1. 显示新建项目向导/对话框
    var newProjectDialog = new NewProjectDialog();
    if (newProjectDialog.ShowDialog() != true) return;
    
    // 2. 创建空白项目数据
    var projectData = new NazikiProjectModel
    {
        ProjectName = newProjectDialog.ProjectName,
        CreationTime = DateTime.Now
    };
    
    // 3. 创建空白 StoryboardRoot（含默认 SceneController）
    var storyboard = _entityFactory.CreateEmptyStoryboard(); // 新增方法
    
    // 4. 初始化 Context
    Context = new ProjectDataContext(_messageBroker)
    {
        ProjectData = projectData,
        Storyboard = storyboard,
        StoryboardMeta = new StoryboardMeta()
    };
    
    // 5. 可选：导入谱面
    if (newProjectDialog.ImportChart)
    {
        // 触发导入谱面流程
    }
    
    // 6. 刷新全 UI
    RefreshAllUIAfterProjectLoad();
});
```

### 方案 2：预览画布实现 WYSIWYG 渲染（这个方案最后再做）

**目标**：在 Canvas 上实时渲染故事板对象，支持选中和拖拽。
故事板所需要的原游戏画面逻辑源码存储在“cytoidplayer”文件夹里，在进行搭建这个功能模块之前需要进行代码迁移。

#### 2.1 实现 `GlobalRenderEngine` 的 Canvas 渲染

当前 [`UI/Rendering/GlobalRenderEngine.cs`](file:///d:/Naziki_Editor/Naziki Editor/Naziki Editor/UI/Rendering/GlobalRenderEngine.cs) 已存在，但未接入 Canvas。需要：

1. **基础渲染层**：在 `CanvasControl` 的 800×600 Canvas 上绘制：
   - 坐标网格（stageX/stageY 参考线，中心十字线）
   - note 区域边界（noteX:0-1, noteY:0-1 → 映射到 stage 坐标系）
   - 所有可见对象（opacity > 0 且 time 在当前播放位置）

2. **对象渲染**：
   - Sprite：加载图片，按 width/height/scale/rotation 渲染
   - Text：按 text/size/color/align 渲染文字
   - Line：按 pos 端点绘制线段
   - Video：显示视频占位帧

3. **交互层**：
   - 点击对象 → 选中（高亮边框 + 拖拽手柄）
   - 拖拽对象 → 实时更新 x/y 坐标
   - 右键 → 上下文菜单（编辑属性、删除、复制）

#### 2.2 接入 `IAudioSyncEngine` 实现同步预览

将 [`AudioSyncEngine`](file:///d:/Naziki_Editor/Naziki Editor/Naziki Editor/Core/Audio/AudioSyncEngine.cs) 的当前播放时间传给 Canvas，根据 `time` 属性决定哪些对象可见、哪些关键帧生效。
